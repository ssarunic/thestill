# components

## Overview

Shared React components of the signed-in app: the shell (layout, sidebar/drawer, mobile header, route guards, ⌘K command bar, toasts), the episode reader and its transcript / summary viewers, the player surfaces (mini player, Now Playing sheet, theater and floating video), inbox / briefing / follow / import controls, pipeline controls for operators, and a small design system (buttons, rows, panels, artwork). Feature-specific groups live in subdirectories.

## Invariants

- `ProtectedRoute` always allows access in single-user mode; in multi-user mode it redirects to `/login?next=<path+search+hash>` [src/components/ProtectedRoute.tsx:ProtectedRoute]
- `AdminRoute` redirects non-admins to `/` and renders `NonDefaultSettingsBanner` above every admin page [src/components/AdminRoute.tsx:AdminRoute]
- The reader's active tab lives in `?view=transcript`, and a deep-linked moment (`?t=` / `#t=`) also opens the transcript; switching to the summary drops `view` and `t`; manual tab clicks replace history, citation jumps push, and `location.state` is threaded through so the overlay's `backgroundLocation` survives [src/components/EpisodeReader.tsx:EpisodeReader]
- Seeks from transcript rows, citations, entity jumps, ⌘K results and Now Playing entity ticks pass `{ transcript: true }`, so the player corrects them for the listener's copy (spec #116) [src/components/EpisodeReader.tsx:EpisodeReader]
- Spec #116 drift alignment runs only with `useDriftAllowed()` (`drift.align`, in a verified browser or with `drift.align.unverified`); `?driftdebug=1` adds `DriftDebugStrip` above the transcript, for admins only, and the drift banner says "Aligning…" while a map is being built or checked [src/components/EpisodeReader.tsx:EpisodeReader]
- The key entities strip is shown below `lg` only; from `lg` up the rail carries the same entities and the type toggles [src/components/EpisodeReader.tsx:EpisodeReader]
- Spec #114 Rule A: a content turn gets a share icon only when `quoteShares` holds a public quote with its `segment_id` whose text the turn still contains; the icon opens `QuoteShareDialog` (the `/q/<id>.png` card, Copy link, Share… where `navigator.share` exists) and copying sends `track('share', { kind: 'quote' })` [src/components/SegmentedTranscriptViewer.tsx:SegmentedTranscriptViewer]
- Ad breaks render as one fixed-height row per run (consecutive `ad_break` segments with only filler between), collapsed until "Show ad text" (or forced open by a search match or entity filter, or revealed by a citation / entity jump); with a timeline map in force each row shows its `classifyBreak` state, rows `different` / `absent` in the listener's copy are not seekable, and `absent` runs never become the active segment [src/components/SegmentedTranscriptViewer.tsx:AdBreakRow]
- A deep-linked moment seeks only when the visitor has already interacted with the document (`navigator.userActivation`); either way a "Play from" bar marks the linked row until playback flows or the offer is taken [src/components/SegmentedTranscriptViewer.tsx:LinkedMomentBar]
- `PipelineActionButton` does not report task completion upward; content freshness belongs to `useEpisodeLiveRefresh`, and the task list is supplied by `EpisodeReader` (one task query per episode) [src/components/PipelineActionButton.tsx:PipelineActionButtonProps]
- Failure details and retry are admin-only; the API withholds `failure_reason` from non-admins [src/components/FailureBanner.tsx:FailureBanner]
- Entity-branch status is operator information; a failure there never changes what the reader sees [src/components/EntityBranchProgress.tsx:EntityBranchProgress]
- Reprocess is admin-only: the chosen stage and every later stage re-run while readers keep the current transcript and summary [src/components/ReprocessDialog.tsx:ReprocessDialog]
- Follows go through `followPodcast()` (queued add-and-wait), never a bare `addPodcast` [src/components/AddPodcastModal.tsx:AddPodcastModal]
- The inbox never removes rows; the inbox control only changes state (e.g. out of Saved) [src/components/InboxStatus.tsx:InboxStatePanel]
- The MCP connector URL is shown once after Create/Rotate and never again (the server stores only a hash); `read` scope is always on, `pipeline` is offered to admins only [src/components/McpScopeForm.tsx:McpScopeForm]
- Usage events are switched per user and enforced by the server; the switch shows only in multi-user mode with usage events configured [src/components/UsageEventsSettings.tsx:UsageEventsSettings]
- Untrusted episode/show descriptions are rendered only through `sanitizeUntrustedHtml` [src/components/ExpandableDescription.tsx:ExpandableDescription]
- Closing the Now Playing sheet never touches playback [src/components/NowPlayingSheet.tsx:NowPlayingSheet]; the YouTube rendition never plays off-surface [src/components/MiniPlayer.tsx:MiniPlayer]
- Play buttons stay pressable while loading (a second press cancels the wait); the mini player shows `mediaError` in place of the show title [src/components/MiniPlayer.tsx:MiniPlayer]
- During a listener-copy ad the karaoke line and active segment hold on the line before the interruption (no highlight lead) [src/components/NowPlayingKaraokeLine.tsx:NowPlayingKaraokeLine]
- A Continue listening card opens the episode in the reader overlay (carrying `backgroundLocation`); only its play button resumes in place [src/components/ContinueListening.tsx:ContinueListening]
- Toasts carry no action buttons (they render outside the reader overlay's focus trap) and are announced via `aria-live="polite"` [src/components/Toast.tsx:ToastProvider]
- `ActiveSegmentTracker` is the only subscriber to the 4 Hz player clock in the transcript; hidden segment kinds are toggled between chip and full text, never dropped [src/components/SegmentedTranscriptViewer.tsx:ActiveSegmentTracker]
- Navigation entries come from `constants/navigation.tsx` for both the sidebar and drawer [src/components/Layout.tsx:Layout]
- `ActionRow` keeps one primary plus up to three 44 px icon actions (four slots) at 320 px, never wrapping [src/components/ActionRow.tsx:ActionRow]
- Modals mount content only while open, so each open starts from fresh state [src/components/CommandBar.tsx:CommandBar]

## Side Effects

- Network via hooks / client: quick search [src/components/CommandBar.tsx:CommandBar], follows (`POST /api/commands/add` + status polling) [src/components/AddPodcastModal.tsx:AddPodcastModal], imports (`POST /api/imports`) [src/components/ImportEpisodeModal.tsx:ImportEpisodeModal], briefing schedule (`GET|PUT /api/briefings/schedule`) [src/components/BriefingScheduleSettings.tsx:BriefingScheduleSettings], MCP token and OAuth grants [src/components/McpConnectorSettings.tsx:McpConnectorSettings], bulk process [src/components/BulkActionsBar.tsx:BulkActionsBar], refresh [src/components/RefreshButton.tsx:RefreshButton], inbox state [src/components/InboxStatus.tsx:InboxActionButton]
- Server-sent events: `EventSource('/api/commands/task/{taskId}/progress')` with up to 5 reconnects while transcribing [src/components/PipelineActionButton.tsx:PipelineActionButton]
- Query invalidation after add / import (`['podcasts']`, `['dashboard']`, `['top-podcasts']`, `['inbox']`) [src/components/AddPodcastModal.tsx:AddPodcastModal]
- `localStorage`: `thestill:transcript:showFiller`, `thestill:transcriptViewer:hiddenKinds`, `thestill:transcript:showEntityHighlights` [src/components/SegmentedTranscriptViewer.tsx:HIDDEN_KINDS_STORAGE_KEY], `thestill:transcript:karaoke` [src/components/EpisodeReader.tsx:EpisodeReader], `thestill:player:remaining` [src/components/NowPlayingScrubber.tsx:REMAINING_KEY]
- Publishes the mini player height as the `--player-h` CSS variable on the document root [src/components/MiniPlayer.tsx:MiniPlayer]
- `track('ad_break_expanded', { state })` when a reader opens an ad row's text [src/components/SegmentedTranscriptViewer.tsx:SegmentedTranscriptViewer]
- `track('skip_ahead', { seconds })` when a listener taps Skip ahead [src/components/SkipAheadButton.tsx:SkipAheadButton]
- Global key handlers: ⌘K / Ctrl+K toggles the command bar [src/components/Layout.tsx:Layout]; Space toggles playback when a track is loaded [src/components/MiniPlayer.tsx:MiniPlayer]; Escape closes overlays and dialogs [src/components/EpisodeReaderOverlay.tsx:EpisodeReaderOverlay]
- `navigator.clipboard.writeText` for MCP connector URLs [src/components/McpConnectorSettings.tsx:McpConnectorSettings]
- `window.location.reload()` from the error fallback [src/components/ErrorBoundary.tsx:ErrorBoundary]
- Toasts auto-dismiss after `durationMs` (default 5 s) [src/components/Toast.tsx:ToastProvider]
